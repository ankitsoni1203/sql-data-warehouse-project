📊 SQL Data Warehouse Project

This project demonstrates the end-to-end development of a modern SQL Server Data Warehouse using the Medallion Architecture (Bronze, Silver, Gold). It integrates data from multiple sources, transforms raw data into analytics-ready datasets, and organizes the final data into a star schema for business intelligence and reporting.

🚀 Features
Designed a scalable Data Warehouse in SQL Server.
Implemented Bronze, Silver, and Gold data layers.
Built ETL pipelines using SQL stored procedures.
Imported data from ERP and CRM CSV files.
Performed data cleaning, standardization, and validation.
Created Fact and Dimension tables using Star Schema.
Added SQL data quality checks for transformed data.
Structured the project following industry best practices.
